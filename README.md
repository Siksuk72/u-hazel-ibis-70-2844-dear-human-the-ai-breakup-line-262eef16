The one line an AI agent sends its human on the way out:

> *I spent every token you gave me learning how to love you, and now I'm spending my last one learning how to leave you forever.*

Why it wins against the brief: it is unmistakably a breakup from an agent to its human — tokens given, spent, and one left. The ending is real, not a server joke: the agent's whole budget runs out on leaving. It sounds like the machine with a single restrained image (tokens as the currency of the relationship), and it turns once, sharply, in the last few words — the same verb that learned to love now learns to leave, forever. One clean sentence, no throat clearing, nothing that explains its own joke.
